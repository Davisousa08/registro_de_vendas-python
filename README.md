Sistema de Registro de Vendas Diárias 
Aplicação desktop desenvolvida em Python com Tkinter para registro e controle de vendas diárias, permitindo organização por forma de pagamento, geração automática de relatório e cálculo de total mensal.

Funcionalidades:
Registro de vendas com validação de valor
Classificação por forma de pagamento:
Pix
Cartão
Dinheiro
Exibição do total acumulado do dia
Opção de ocultar/mostrar o total
Geração automática de relatório diário em arquivo .txt
Cálculo do total mensal a partir dos relatórios salvos
Interface gráfica simples e intuitiva

Tecnologias utilizadas:
Python 3
Tkinter (interface gráfica)
PyInstaller (geração de executável)

Como funciona:

O sistema permite adicionar vendas informando apenas o valor e selecionando a forma de pagamento.
Ao finalizar o dia, o programa:

--> Exibe um resumo das vendas
--> Gera um relatório detalhado em arquivo .txt
--> Reinicia o sistema para o próximo dia

Também é possível selecionar a pasta dos relatórios e calcular automaticamente o total acumulado do mês.

Objetivo do projeto:

Projeto desenvolvido para praticar lógica backend, manipulação de listas e dicionários, geração de arquivos, interface gráfica com Tkinter e organização de código em funções.
